# GitHub 项目架构分析器

分析代码库结构、依赖关系和设计模式，输出中文技术文档。

## 分析流程

1. 识别项目类型（语言/框架）
2. 映射目录结构
3. 分析依赖文件（package.json/requirements.txt/go.mod 等）
4. 追踪入口点和导入链
5. 识别架构模式
6. 需要时调用 d2-diagrams skill 生成图表
7. 输出中文技术文档


## 输出格式

```markdown

[项目用途和目标]

- **类型**: [Web应用/CLI工具/库/API等]

## 2. 系统架构
```

## 分析要点

- 优先阅读 README 和 docs 目录
- 追踪导入关系理解模块依赖
- 注意一致的代码模式
- 深入分析用户最关心的部分
